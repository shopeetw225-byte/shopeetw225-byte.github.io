# 第四期视频

Claude 对话总结｜整理日期：2026年10月5日｜对话覆盖：2026年10月2日至10月5日

第四期最终定为《放置事务所》**离线篇**，承接第三期“挂机篇”：第三期讲游戏开着怎么挂，第四期讲关掉游戏以后如何获得、查看和收取收益。**最终三版已完成，均为3分49秒、42句台词、必剪曼波配音和0.9倍速新版主题曲。** 10月5日，旧英文成片及本期英文字幕、配音、台词已移入废纸篓。

## 主题怎么确定

最初拟做“学院研究篇”，核对过研究系统，也建过相关制作框架。用户要求“这个先不做，看下第三期对话”，随后按第三期的拆分方案改为离线篇。因此“研究篇”是放弃的早期方向，不是本期成片主题。

本期主要演示存档通关56关、处于当时 Demo 的60关范围内。游戏更新后，离线简报、学院、酒馆、要塞、标题和英雄页都曾用 `6acf4f86` 版本重新录制。后续再出片直接使用已入库素材，不重复录。

## 最终文案与表达要求

开场固定为“各位股东大人，我是倦猫”，随后使用用户指定原话：“我们的Demo会在Steam新品节上架，正式版预计12月3号发售，感兴趣的可以先加个愿望单”。这是当时稿件中的计划表述，本次没有重新核实发售安排。

- 不加“第4期 离线篇”大字卡，不重复讲“我正在做什么游戏”，不说“下期再讲”。
- 经历要穿插在对应玩法里，像朋友聊天，说明当时在做什么、有什么感受；不单列笼统的人设介绍。
- 只使用本人确认过的经历。早期曾直接加入未确认草稿，之后通过勾选确认、删改纠正。
- 结尾改为“大家有什么好的建议，欢迎在评论区告诉我”，不再走感谢群友配音的方向；第四期原本没有那句感谢，无须删除现成内容。

最终保留的四处经历：

| 对应玩法 | 保留内容 |
|---|---|
| 自动入账 | 不喜欢看广告，所以收益直接到账 |
| 装备掉落 | 看到数值忍不住算一算（10月5日删掉“我平时是做数据分析的”，每期都提太啰嗦） |
| 一键最优 | 懒得一件件比较装备，新装备多了头大，所以做一键最优 |
| 建筑停产 | 周末出去玩一整天，回来发现四座建筑停产，觉得心疼 |

未确认的“每天早上先看简报”“上班离开十二小时”“出门前点研究”“仓储最先研究”“睡前派遣开研究”等，不应再当作本人经历使用。

## 按新版修正的关键说法

- 删除“装备只在离线结算时发”的旧说法。新版在线自动委托也掉装备，改为“平均两个小时掉一次，离开这段时间掉的都列在这儿”。
- 增加研究排队：学院5级增加一个排队位，15级再增加一个；前一项完成后接着做，离线同样推进。
- 增加传令兵：离线简报会列出建筑满仓后少收到的资源。
- “一键最优”只处理符合规则、能提升出战队战力的装备；带特殊效果的装备保留给玩家自己挑。
- 区分离线自动委托收益与建筑存量：建筑产出不直接进入离线简报，回要塞另收。游戏部分说明与实际效果不一致时，视频按实测行为讲。

繁中版不是繁中游戏界面重录。字幕做简转繁，不强行改成台湾用词，以免和口播不一致；标题为“我的獨立遊戲／《放置事務所》”。竖屏字幕优先按标点和词语换行，不拆词，不压住游戏画面。

背景音乐从早期“无BGM”改为游戏新主题曲 `main_theme`，放慢到0.9倍、不变调。只用必剪曼波；改台词只重配改动句，其他按原文复用。最终补配开场和评论区两句，其余40句保留。
