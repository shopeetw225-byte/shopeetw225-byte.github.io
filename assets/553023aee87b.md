# 封面制作

Claude 对话总结｜整理日期：2026年10月5日｜对话覆盖：2026年9月30日至10月5日

这段对话从第一期封面的多轮风格试验，逐步确定了按视频分文件夹、以游戏角色和卖点为中心的系列封面规则。**最新默认是四张：B站、小红书、抖音、繁中竖屏；每张同时保存 PNG 和 JPG，不默认制作英文版。** 第四期的最新要求是从成片选代表性画面，但在开始选图后遇到额度限制，尚未生成封面。

## 当前有效的封面规则

- 文件统一放在 `视频制作/封面/`，按对应视频或期数建子文件夹。
- PNG、JPG 放在同一期文件夹里，不再按格式分两个总目录；上传通常使用 JPG。
- 备用稿在文件名标注“备用版”和角色名称，不能与正式稿混淆。
- 默认以英雄动态立绘中的清晰画面为主图，文字参考第一、二期和“放置之路”作者的封面写法。
- 不再用“失业后、我用AI做游戏”等人设标题；不写容易过时的具体英雄数量。
- 简中常用两行：第一行“不抽卡的放置游戏”，第二行说明这一期最直接的卖点。
- 样式为粗体大字、黄橙与红色渐变、粗黑描边和阴影；Logo、愿望单提示应清楚，避免挡住人物面部、王冠或关键画面。
- 竖图关键文字和主体放在中间3:4安全区域，缩小检查可读性。这里记录的是项目采用的设计做法，本次没有重新核查各平台裁切规则。

| 默认版本 | 尺寸 | 语言 |
|---|---|---|
| B站 | 1920×1080 | 简中 |
| 小红书 | 1080×1440 | 简中 |
| 抖音 | 1080×1920 | 简中 |
| 繁中竖屏 | 1080×1920 | 繁中 |

第四期“从视频中选代表性画面”的明确要求优先于“默认英雄立绘”，不应机械沿用同一角色模板。

## 风格如何演变

1. **第一版：游戏标题底图加人设文字。** 使用 Steam 预告片片尾，写“失业后／我用AI做独立游戏？”，AI大写突出。用户认为太板正。
2. **第二版：VTuber式斜排。** 放大文字、倾斜排版、多问号、双描边和装饰，并扩展小红书、抖音、英文横竖版。最初居中版随后按要求移入废纸篓。
3. **第三版：参考放置之路作者。** 参考 B站“活到老刷到老”的“我的独立游戏／卖出2万份啦！”系列，采用两行渐变粗字、实机或立绘主图、Logo及愿望单角标；原VTuber风格停用。
4. **去人设。** 用户明确“不立人设了”，曾改为“不抽卡的放置游戏／146位英雄任你搭配！”。后来进一步要求不写具体英雄数量，改用首领招募等具体卖点。
5. **形成四版默认。** 10月3日明确以后默认B站、小红书、抖音加繁中竖屏，不默认英文，主图改用英雄角色。

这些是先后替换的方案。不能把“VTuber斜排、多问号”“146位英雄”或“按PNG和JPG分总文件夹”当成仍然有效的要求。

## 各条视频的最终决定

### 第一期 英雄与装备介绍

**正式版用卡洛，白冠王保留为备用版。** 用户先选首领卡洛，试过白冠王后说“还是先上面那个卡洛”，随后要求白冠王也保存并标明备用。

- 主图：卡洛（雾羽猎爵）动态立绘，选面具和白羽清晰、受光较好的画面。横版角色在右、文字在左侧暗处。
- 简中文字：“不抽卡的放置游戏／首领打赢就归你！”
- 历史英文版：“IDLE GAME, NO GACHA / BEAT A BOSS, IT'S YOURS!”
- 白冠王备用版采用王座、王冠和权杖画面，文件名末尾加 `_备用版_白冠王`。
- 当时各做五种版式：B站、小红书、抖音、英文横屏、英文竖屏。正式与备用各五张，每张PNG和JPG各一份。

本次目录核对：该期共10张PNG、10张JPG，与正式及备用各五种版式相符。

### 第一个预热视频

对应 `19秒小视频` 中的“开场片头_上架Steam”，早期目录名是“小剪辑视频”。

- 主图：辉光圣堂武士动态立绘。选择立绘的原因是缩小后比编队界面更容易看清，且英雄在视频中出现过。
- 中文：“我的独立游戏／上架Steam啦！”
- 英文：“MY INDIE GAME / IS ON STEAM!”
- 交付简中横屏、简中竖屏（小红书3:4）、英文横屏，共三种，每种PNG和JPG。
- 文案单独放 `视频制作/文案/第一个预热视频_开场片头上架Steam_标题与文案.txt`。

当时文案区分“商店页上线、加入愿望单”与“正式发售、可玩”，不把上架商店页写成已经发售。旧说法“五星英雄明码标价”按版本改为招募券指定招募；QQ群号当时留占位待补。这些是当时文案状态，发布前仍要看现有文件及实际情况。

### 第二期 站位与配队

最初用编队页截图，文案为“打不过？换个站位！”。用户要求改成“换阵容”，因为内容同时涉及配队与站位；历史英文对应由 formation 改为 lineup。

10月3日又按新默认重做为英雄主图：

- 主角：凯歌圣咏祭司，选择动态立绘中光环明亮的一帧，与片中“牧师放中间罩得最多”的内容对应。
- 简中：“不抽卡的放置游戏／打不过？换个阵容！”
- 繁中：“不抽卡的放置遊戲／打不過？換個陣容！”
- 繁中Logo使用“放置事務所”，角标“Steam 加入願望清單”。
- 四版为B站、小红书、抖音、繁中竖屏，各有PNG和JPG。

原会话当时说旧英文两张暂留；**本次实际目录只有四张PNG和四张JPG**，因此当前库存以四版为准，不能继续断言英文旧稿仍在。本次未追溯其后移走过程。

### 第三期 挂机篇

按用户要求用卡洛，但比第一期拉得更近，让面具、白羽和弩更突出，以区分同角色的两期封面。

- 简中：“不抽卡的放置游戏／挂着就能自动推关！”
- 繁中：“不抽卡的放置遊戲／掛著就能自動推關！”
- 不写“八倍”等可能调整的数值。
- B站、小红书、抖音、繁中竖屏四版，每版PNG和JPG。

制作时修过横版顶部接缝，以及渐隐层把Logo和愿望单按钮压暗的问题。备选第二行“加速不用看广告！”只是建议，用户没有确认替换；第一、三期重复用卡洛的替换建议也没有成为新决定。

历史上曾有 `放置事务所平台宣传/png、jpg、txt` 的结构；目录丢失后从临时副本恢复到 `视频制作/封面/`，再按用户要求改为按视频分类。期间用户取消过整理整个项目，之后不应由封面任务擅自扩大到全项目整理。

投稿标题、简介和置顶评论放在 `视频制作/文案/`，文件名说明对应哪条视频。早期人设版旧文案和旧成片不等于最新封面所对应的内容。
