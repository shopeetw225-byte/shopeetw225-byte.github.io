안녕하세요, Juanmao입니다.

정식판이 12월 3일에 출시돼요. 12일 남았어요! 정식판에서는 Steam 커뮤니티 장터가 열려요~ 장터에 대해 하고 싶은 말이 있으면 댓글로 남겨 주세요.

이번 글도 업데이트 얘기는 아니에요. 데모에서 일하면서 방치하는 법을 이야기해 볼게요. 방치형 게임인데 계속 전체 화면으로 지켜볼 수는 없잖아요.

[h2]방치 중이면 전투를 작은 창으로 줄일 수 있어요[/h2]
전투 페이지에서 "자동 진행"이나 "자동 방치"를 켜 두면 오른쪽 위에 "구석 작은 창으로 축소" 버튼이 있어요. 누르면 전투가 메인 화면 구석으로 줄어든 채 계속 싸워요. 요새나 영웅 같은 페이지로 바로 넘어가도 알아서 줄어들어요.
작은 창을 누르면 전투 화면으로 다시 커지고, 위에 있는 ■는 자동 전투 중지예요.
[img]{STEAM_CLAN_IMAGE}/46216320/f868091d4845f7e29a93a11d3a0ec029ba2fcd1e.png[/img]

[h2]전투를 메인 창 밖으로 끌어내기[/h2]
보조 모니터나 바탕화면 한구석에 두고 싶으면 독립 창으로 만들면 돼요. 방법은 세 가지, 아무거나 괜찮아요:
[list]
[*]전투 페이지 오른쪽 위의 "독립 창으로 분리" 누르기
[*]구석 작은 창 왼쪽 위에 있는 같은 버튼 누르기
[*]전투 화면을 누른 채로 메인 창 밖으로 끌어내기
[/list]
Windows에서는 전투 창 위에 마우스를 올리면 스테이지 이름과 "방치 1시간에 약 ○○ 골드"가 보여요. 더블 클릭하면 메인 화면으로 돌아가요.
먼저 두 가지만 짚고 갈게요:
[list]
[*]초보자 가이드가 켜져 있으면 15스테이지를 깨야 이 분리 버튼들이 생겨요(뒤에 나오는 관리 페이지 버튼도 마찬가지예요). 그 전에는 구석 작은 창만 있어요. 설정에서 초보자 가이드를 끄면 처음부터 다 있어요.
[*]독립 창은 Windows와 macOS 데스크톱용이에요. Steam Deck에서는 구석 작은 창을 쓰면 돼요.
[/list]
[img]{STEAM_CLAN_IMAGE}/46216320/1673955b53fa07e19d242460190d21a13f76fe16.png[/img]

[h2]항상 위에, 투명하게, 다른 창 위에 띄워도 거슬리지 않게[/h2]
설정 → "화면"에서 "전투 창 항상 위에 표시"를 켜면 전투 창이 늘 맨 위에 떠 있어요. 전투 창에 있는 위쪽 화살표 버튼도 같은 스위치예요.
전투 창 오른쪽에 불투명도 슬라이더가 있어서 위아래로 끌기만 하면 돼요. 최저 0%까지 내릴 수 있어요. 너무 투명해져도 걱정 마세요. 마우스를 올리면 잠시 선명하게 보여요. 정 못 찾겠으면 메인 화면 구석의 동그란 버튼을 누르면 다시 불러올 수 있고, 불투명도도 100%로 돌아가요.
mac에서는 먼저 전투 창을 한 번 클릭해야 버튼과 선명한 화면이 나와요. 일부 Windows PC에서는 바탕화면이 비치지 않아서, 내려도 종이색으로 흐려지기만 해요.
[img]{STEAM_CLAN_IMAGE}/46216320/3b91b1fd01542c211a46f8a4dd455a3d8f02922e.png[/img]

[h2]전투 창의 버튼들[/h2]
"⋯"을 눌러 펼치면 순서대로 항상 위(위쪽 화살표), 스피커(게임 전체 음소거), 합치기(굽은 화살표, 메인 창으로 돌아가고 전투는 계속)가 있어요. 맨 오른쪽 겹화살표 "더 보기"를 누르면 화면 비율 전환(16:9 또는 정사각형), 요새·원정·영웅·군비 페이지 버튼, 그리고 "게임 종료"도 나와요. 여기까지 펼치면 창 네 모서리를 끌어서 크기도 바꿀 수 있어요.
게임 소리를 듣기 싫으면 설정 → "오디오"에 "포커스 해제 시 음소거"도 있어요.

[h2]관리 페이지도 따로 창을 띄울 수 있어요[/h2]
메인 화면 오른쪽 위, 내비게이션 깃발 아래에 "이 페이지를 독립 창으로 열기"라는 작은 버튼이 있어요. 영웅, 편성, 주점, 학원, 도감 페이지를 따로 열 수 있어서, 예를 들어 편성 페이지를 보조 모니터에 두고 전투를 보면서 편성을 바꿀 수 있어요.
열어 둔 창과 위치는 기억돼서, 다음에 게임을 켜도 그 자리에 있어요. 시장은 데모에서 열려 있지 않아서 이 페이지는 없어요.
[img]{STEAM_CLAN_IMAGE}/46216320/d41ef5b34c9e44c943875970529b6b9217a56d31.png[/img]

[h2]메인 창을 닫아도 게임이 실수로 꺼지지 않아요[/h2]
전투 창이 밖에 나와 있을 때 메인 창의 ×(mac에서는 빨간 점이나 Cmd+Q)를 누르면 메인 창만 작아지고, 그 김에 한 번 저장도 해요. 전투는 계속돼요.
정말 끄고 싶으면 설정의 "저장 후 게임 종료"나 전투 창 "더 보기" 안의 "게임 종료"를 쓰세요(이 버튼은 두 번 연달아 눌러야 해요).
