# steam宣传

Claude 对话总结｜整理日期：2026年10月5日｜对话主要覆盖：2026年9月29日至10月3日

这段对话完成了《放置事务所》Steam 主预告片的分镜、实机录制、多轮剪辑和三语版本制作。**目前可核对的正式交付是 v20：简中、英文、繁中三版，每版约 52.9 秒。** 10月3日提出用新版游戏重录 v21，并启动了后续会话；截至本次整理，成片目录仍只有 v20，不能把 v21 记为已完成。

## 最终确定的制作方向

- 用真实游戏画面展示英雄收集、招募、升级、装备、编队、战斗、试炼和首领挑战；不加讲解字幕，保留游戏界面文字、片尾游戏标题和愿望单提示。
- 画面规格为 1920×1080、60fps、H.264。交付成片，同时保留剪映素材包，便于后续修改。
- 出镜英雄尽量多、各段尽量换人，优先使用有动态立绘的英雄。宣传用语统一说“英雄”；“升级”和“升阶”、“站位”和“阵型”分别是不同概念。
- 除片尾标题外，不做持续推近。后续用户允许战斗段适当加强冲击感，但最终要求小幅震屏、少量轻闪，避免看着头疼。
- 所有伤害数字来自游戏实机；后期只加强调色、冲击帧和声音，不另造伤害数字。整段光晕方案因让背景发白、数字不清而弃用。
- **这支 Steam 预告片后续修改，简中、英文、繁中必须一起改**，版本号、分镜和三份剪映素材包同步。讲解视频后来“不再出英文版”的约定，没有在这个话题中明确替代预告片三语规则。

## 最终内容顺序

| 顺序 | 内容 | 最终决定 |
|---|---|---|
| 1 | 浏览角色背包卡牌墙 | 加速滚动，体现英雄收集；不用早期的战地图鉴页面 |
| 2 | 酒馆招募 | 招募三名英雄，展示动态立绘和招募成功效果 |
| 3 | 英雄升级 | 三名英雄连续升级；删除升阶演示 |
| 4 | 穿戴装备 | 只留辉光圣堂武士、狂法先知、亡命突锋三人，快速穿戴史诗套装 |
| 5 | 专属装备 | 快速展示多位英雄的专属装备 |
| 6 | 布阵 | 三支不同队伍，各拖动英雄换站位并切换不同阵型 |
| 7 | 普通战斗 | 三场，满编群攻队展示密集伤害、治疗与护盾数字 |
| 8 | 试炼 | v20 新增，约 3.4 秒，位于普通战斗之后、首领展示之前 |
| 9 | 首领展示 | 点选约四名首领，展示动态立绘；删除滚轮翻长列表的部分 |
| 10 | 首领战斗 | 三场首领挑战，最后一场逐渐黑屏 |
| 11 | 片尾 | 音乐随画面淡出，短暂纯黑后标题亮起并响起低沉撞击声 |

原先“招募后点开三名英雄看大图”的独立段落因太乱被删除；单独技能浏览段也已在重新排序时去掉。上述表格是后续迭代的最终顺序，不是最初的 46 秒分镜。

布阵最终显示三次明确变化：第一队锋矢阵→长蛇阵，第二队方圆阵→雁行阵，第三队雁行阵→锋矢阵，每队约 1.7 秒。

v20 的试炼镜头约在 28.7–32 秒：进入试炼之塔第78层，展示“和平／普通／凶险”路线并选择凶险，再打开塔印、切换装备，展示“破晓之刃·5印”和“先锋之心·4印”。三版分别录制对应语言界面。

## 关键修改过程

| 阶段 | 对话中决定的变化 |
|---|---|
| v1 | 46 秒初版，装备开场，含升级与升阶、技能、图鉴和两队布阵 |
| v2–v6 | 加快菜单段节奏；去除持续推近和升阶；混合使用转场；修复片尾闪出一帧游戏画面；标题只在前 1.6 秒轻轻放大，之后静止 |
| v7–v10 | 增加招募、首领展示，重排为收集→养成→编队→战斗；统一用当时新版重录；试过滚轮展示更多首领，并增加三场首领战 |
| v11–v13 | 删除首领滚轮段；穿装备从五人缩到三人；布阵改为三支队伍三种阵型；补强小喇叭能听见的标题撞击声 |
| v14–v16 | 战斗加工后太晃、太闪，按反馈降低：震屏约左右8／上下6像素、0.1秒，每个战斗镜头只留一次轻闪，避开开头转场 |
| v17–v19 | 删除图鉴后点开立绘的三个镜头；标题声一度加得像噪音，最终撤销饱和处理，恢复干净撞击声并稍加音量；用户认可后补英文和繁中 |
| v20 | 三语同时加入试炼难度与塔印，时长约52.9秒，三份素材包各32个镜头 |

片尾的最终偏好是“慢慢黑屏，再出标题”，不要闪一下；标题声要低沉、有电影式冲击感，但不能为了大声变成噪音。v19 恢复干净音色后，用户回复“这个可以”。
